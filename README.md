# 羊磴「价值剩余物」艺术乡建实践

> 新文科实践创新大赛（社会调研赛道）参赛项目 · 四川美术学院 · 羊磴燈组

##  项目简介

以贵州桐梓**羊磴镇**为田野点，围绕焦兴涛教授主导的**羊磴艺术计划**（2012 年至今），研究一类被常规治理视野漏掉的对象——**"价值剩余物"**：功能退场后、记忆价值尚未被社区自身识别与激活的"第三状态"（烟头、塑料瓶、废弃蜂箱）。

项目把艺术家在羊磴做的事拆解为可迁移的五个动作——**识别 → 转译 → 共创 → 再嵌入 → 评估**，并总结出三条低门槛转化路径：

| 路径 | 针对对象 | 羊磴案例 |
|---|---|---|
| 经济计量入口 | 消费残余 | 烟头计划（10 元/斤 → 环境行为改变） |
| 本土命名转译 | 灾害痕迹 | 鲤鱼上树（方言"做个球" + 洪水记忆） |
| 空间迁移锚定 | 产业废墟 | 蜂巢记忆（生产工具 → 公共情感载体） |

核心结论：**羊磴真正值得带走的不是那几件雕塑，而是一套不需要艺术家在场也能跑起来的方法。作品依赖美院，方法不依赖。**

##  调研数据速览

- 五次田野驻留（2025.4 / 2025.6 / 2025.9 / 2026.3 / 2026.6），累计 15+ 天
- 村民访谈 20 余人次，田野文本 10 万字，访谈录音 20+ 小时
- 核心行动者：胡砚坤（木匠 → 乡土美术馆馆长）、戴祥均（养蜂人）等
- 曾在 SEPR 2026 国际研讨会（Society for Ecological and Cultural Restoration）作学术汇报

##  使用说明

- `report/` 三个文件合起来是一份**"如何把一篇论文式报告改成竞赛申报文本"**的完整过程档案：评委要求落点 → 字数变化 → 三段核心新增 → 逐段去 AI 味修订。
- `presentation/答辩问题库与参考答案.txt` 按十类场景组织（评委开场高频区、创新性、数据科学性、推广落地、团队执行、伦理反思、细节质疑、新文科特色、宏观对比、压力测试），文末附答辩策略速查。
- `tools/` 中的两个 Python 脚本无第三方依赖，可直接运行：`python tools/改写字数校验.py`。

## 二、5 分钟汇报逻辑（建议 10–12 页）

1. **钩子开场（15s，1 页）**：新标题 + 一句话："在羊磴，一斤烟头卖十块钱，鲤鱼会爬上树，废弃的蜂箱里又住进了蜜蜂。"
2. **问题切入（45s，1–2 页）**：煤矿关闭、周期性洪水、整村易地搬迁 → 三类"无用之物"（烟头/塑料瓶/蜂箱）= 三种断裂的人地关系。
3. **概念与机制（45s，1–2 页）**："价值剩余物"定义 + 五步机制图 + 三条路径。评审最看重落地，此页只讲逻辑框架，不堆理论。
4. **三个案例（约 2 分钟，3 页，每页一案例一钩子）**：
   - 烟头计划 = 经济入口（10 元/斤 → 行为改变）；
   - 鲤鱼上树 = 本土语言（方言"做个球"+ 洪水记忆 → 污染可视化）；
   - 蜂巢记忆 = 空间迁移（生产工具 → 公共情感载体 → 蜜蜂重新定居）。
5. **成效与证据（45s，1–2 页）**：数据 + 人物变化（胡砚坤从木匠到馆长等）+ 回访发现的"经济激励减弱后行为仍持续"这一关键验证。
6. **调研与展望收尾（30s，1 页）**：调研证据链 + 未来三步（回访羊磴/拓展案例/小型文化项目落地）。

## 三、现有 PPT（22 页）修改清单

1. **砍页数**：22 页对 5 分钟太重（平均每页 13 秒）。删掉：摘要页（报告里有，口述即可）、引言页（与问题页重复）、结语大段文字页、部分章节隔页与二维码页，压到 10–12 页。
2. **换逻辑**：现在是论文式结构（研究问题→摘要→引言→结语），改为竞赛式：问题 → 概念 → 三个案例 → 成效证据 → 推广价值。原"案例目录式结构"表格（9 号页）信息很好，可精简后当作三个案例前的总览页。
3. **减文字**：所有整段论文式文本（如摘要页 400+ 字、结语页 600 字、引言页）改为"一个论点 + 一张现场照片 + 三个短句"。长文移入演讲者备注。
4. **补证据页**：新增"调研时间线 + 数据"页和"成效回访"页，对应 60 分与 +5 分。
5. **视觉统一**：黄色标题字在照片上辨识度不稳，建议统一加深色蒙版或色块底；7 号字表格字号过小，投屏不可读，改为图形化三列对比。
6. **人物出场**：把"胡砚坤、戴祥均、全安权"等村民的真实姓名和照片放进成效页——评审对"具体的人的具体改变"最敏感。

## 四、参赛标题建议

现有标题《"价值剩余物"的再生：生态艺术唤醒乡村文化记忆的羊磴实践》问题："价值剩余物"是自创学术概念，评委第一眼无感；且句子偏长偏正。参考本届其他团队命名风格（主标题意象化 + 副标题点题，如"锈苗纪""鲤鱼上树式"的具象词更抓人）及全国获奖案例（"点泥成金""流塑生境""利废修旧"），建议：

**首推**
1. **《十元一斤的记忆——烟头、鲤鱼与蜂箱的羊磴乡村艺术再生》**（"十元一斤"是烟头计划真实机制，具体、有悬念，答辩可自然展开）

**备选**
2. 《垃圾会记得——羊磴"价值剩余物"的生态艺术实践》（情感钩子最强，概念收进副标题）
3. 《鲤鱼上树之后——羊磴废弃物的文化再生实验》（借已在地的作品名，有故事感）
4. 《别急着扔——艺术唤醒羊磴乡村的文化记忆》（口语化、亲民）
5. 《剩余的万岁——羊磴生态艺术与乡村记忆再生》（冒险但记忆度高，慎用）

> 提醒：标题改动需同步改报告封面、PPT 封面与邮箱正文；若评审系统已按原题报名，先确认能否改题。

## 五、烟头计划互动小游戏：建议"备而慎放"

**结论：可以展示，但不要现场切程序，用 30 秒内嵌录屏 + 答辩备用。**

- 支撑理由：它直接对应 30 分"创意创新"（创新设计手法、数字化情景再现），是 29 支队伍里少见的差异化亮点，也是团队"教育传播"分工的成果。
- 风险：5 分钟极紧，现场切窗口/加载卡顿会吃掉时间且打断节奏；单机程序在会场设备上的兼容性不可控。
- 推荐做法：在"烟头计划"案例页嵌入 **≤30 秒无声录屏**（或 GIF），口播一句"我们还把烟头计划的情景做成可交互的情景还原小游戏"；把可运行程序拷入 U 盘 + 准备二维码，**答辩环节若评委感兴趣再现场演示**——这样既保时间闸门，又能变成答辩的加分互动。

# 四、落地方案：脱离艺术家与美院在场的可操作路径

## 4.1 前提与转译思路

前文已经说明，这套流程能够迁移的是其中的思考逻辑，而不是羊磴的雕塑作品本身。真正限制迁移的条件，是羊磴十余年积累的艺术家驻场。如果把这个条件抽掉——没有艺术家长期驻村、没有美院团队持续投入——方案是否还成立，是本节要回答的问题。

答案是成立，但需要把"艺术家承担的功能"拆开，交给村里本来就有的人和本来就在运行的事。田野里艺术家实际做了四件事：判断什么东西值得留下（识别）、给它起一个当地人听得懂的名字（命名）、把人组织起来一起做（组织）、把过程和物的来历记下来（记录）。这四件事没有一件必须依赖专业艺术训练，羊磴自身已经给出证据：烟头计划的发起者胡砚坤是搬迁村民，原为木匠、道士；"鲤鱼上树"的形式来自一句方言"我做个球"；蜂箱雕塑的产业记忆由养蜂人戴祥均提供。艺术家的实际作用是点燃和组织，不是唯一的知识来源。

因此本方案的核心转译是：以"识别、命名、组织、记录"四项可分工的动作，替代"艺术家个人在场"这一不可复制的条件，并分别接入三类已经在全国运行、且不需要艺术家参与的制度通道——农村生活垃圾积分兑换、以工代赈、乡村（类）博物馆建设。

## 4.2 政策接口

《乡村全面振兴规划（2024—2027年）》把"提高生活垃圾治理水平，推进源头分类减量、就地就近处理和资源化利用""完善生态产品价值实现机制""重塑乡村文化生态"列为同期重点任务[9]，本方案的环境治理目标与文化记忆目标，分别对应前两项与第三项，无需另设政策依据。

以工代赈提供了人员与资金的合法通道。2025年以工代赈中央投资规模达355亿元，实施项目7000余个，劳务报酬占中央投资的比例进一步提高至40%以上；政策明确以工代赈项目可不招标，鼓励"村民自建""乡建公司承建"，并推行"乡镇政府+村级合作社（村民项目理事会、乡建公司）+群众"的劳务组织模式[10]。回收点修整、公共空间清理、记忆角施工等人工用量大、材料成本低的小型工程，可以直接做成以工代赈项目，村民既出工又拿报酬，替代艺术家带资进村的投入。

乡村（类）博物馆解决了"记忆容器由谁建"的问题。2021年国家文物局将浙江乡村博物馆建设列为试点，浙江将其纳入《浙江省文物博物馆事业发展"十四五"规划》，提出建设1000家的目标；截至2025年，浙江已累计建成1000家乡村（类）博物馆，实现市、县全覆盖，并建立高校与省市博物馆专家结对帮扶机制，展品多来自村民捐赠，由本村人参与讲解[11]。这说明记忆空间可以脱离艺术家长期驻村，依靠制度化的帮扶关系落地。

## 4.4 人员分工：谁来做艺术家做的事

表4-2 艺术家功能的在地承接

| 原本由艺术家承担 | 在地承接者 | 依据 |
| --- | --- | --- |
| 识别：判断什么值得留下 | 村"两委"、驻村工作队、老艺人（养蜂人、护林员、木匠） | 羊磴蜂箱的产业记忆由养蜂人戴祥均提供；西藏洛扎柏日村"绿色银行"由驻村工作队与村"两委"设计并运营[15] |
| 命名：起一个当地人听得懂的名字 | 村民议事会、乡贤、村小师生 | "鲤鱼上树"取自洪水记忆，"做个球"取自方言（见3.2） |
| 组织：把人动员起来 | 妇女主任、网格员、保洁员、村小教师 | 遵义仁怀龙井镇由村"两委"与党员代表组成评定组，每月入户打分，季度兑换[12] |
| 施工：兑换点与记忆角的空间整理 | 本村劳动力，按以工代赈"村民自建"或乡建公司承建 | 以工代赈项目可不招标，鼓励村民自建[10] |
| 记录：物的来历与口述 | 村小教师与学生（绘画、口述）、村级文化管理员 | 浙江乡村博物馆鼓励村民参与讲解与展陈互动[11] |
| 专业指导（可选，非必需） | 与国有博物馆、高校结对帮扶 | 浙江已建立高校与省市博物馆专家结对帮扶机制[11] |

分工的关键在于：不许诺某一件作品，只固化一组动作。村庄缺少任何一类角色时，可由相邻角色兼岗，但不建议由外部人员长期代做记录与命名，否则撤离后机制即失效。

## 4.5 十二个月实施节奏

1. 第1—2月 摸底建账。以村民小组为单位清点三类剩余物——消费残余（烟头、塑料瓶）、产业遗存（蜂箱、农具）、灾害遗留（洪水冲积物），逐件登记"谁用过、何时用、怎么用"，形成"物—人—事"台账。这一步在羊磴由研究团队完成，迁移时可由村"两委"与驻村工作队完成。
2. 第3月 定标准。参照已运行村庄的比价制定本村兑换标准，例如江西新干堆背村每公斤分类垃圾5分、30分换一支牙膏、100分换一袋洗衣液[16]；标准经村民代表会议通过后上墙公示，并配套正负面清单。
3. 第4—6月 试点运行。设1个兑换点，优先依托村委闲置房、小卖部或既有积分超市，固定每月1—2个兑换日。参照陕西吴堡县设5个标准化兑换点、马鞍山博望镇每月20日集中兑换的做法[14,17]。
4. 第7—9月 共创与再嵌入。把已登记物件转为村史角、记忆角的公共陈列，邀请长者命名、讲解，让学生参与绘制说明牌。这一步对应羊磴蜂箱进入镇区公共空间的功能转换，但投入远低于雕塑制作。
5. 第10—12月 评估与固化。按参与户数、回收量、行为持续性、空间使用频次四项做记录，纳入村规民约与既有积分制，避免机制随外部人员撤离而中断。

上述七例中，除羊磴外均非艺术机构主导，全部由村级组织、驻村工作队或地方政府运行，且均有公开数据。它们验证的是同一件事：让废弃物重新进入社区关系，不需要艺术家在场，需要的是定价规则、组织者和一处公共空间。羊磴提供的是"为什么值得做"的判断依据，这些案例提供的是"没有艺术家也能做成"的操作依据。

## 4.7 适用边界

三点限制需要明确。其一，方案依赖村级组织具备基本的动员与台账能力；若村"两委"组织能力薄弱，应先依托驻村工作队过渡，不宜直接铺开。其二，兑换机制需要稳定的变现渠道与集体经济的托底，兑换标准若长期高于回收变现价，机制会在补贴停止后失效——羊磴回访中观察到的"经济激励减弱后行为部分持续"，恰恰说明还需要命名、组织、记录三项动作接续，单靠收购价留不住行为改变。其三，记忆角必须避免千村一面，浙江经验中"展品来自村民捐赠、由本村人讲解"是前提，否则记忆转化会退化为陈列工程，重蹈形式化乡建的覆辙。
